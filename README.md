# Board Games

One-laptop, no-phones social deduction games. Gather round one screen and play.

**▶ Play now: [03shraddha.github.io/board-games](https://03shraddha.github.io/board-games/)**

Open the link on any laptop, pick a game, and follow the on-screen prompts. No install, no accounts, no phones — the laptop is the board and the narrator. (You can also open any `.html` file below directly in a browser.)

| Game | Players | Play |
|------|---------|------|
| **Secret Hitler** — hidden fascists try to pass policies and elect Hitler | 5–10 | [play](https://03shraddha.github.io/board-games/secret-hitler.html) |
| **The Resistance: Avalon** — good knights run secret quests while hidden evil sabotages them | 5–10 | [play](https://03shraddha.github.io/board-games/avalon.html) |
| **One Night Ultimate Werewolf** — one night of role-swapping, then one vote to catch a werewolf | 3–10 | [play](https://03shraddha.github.io/board-games/one-night-werewolf.html) |
| **Spyfall** — everyone shares a secret location except one spy bluffing to blend in | 3–8 | [play](https://03shraddha.github.io/board-games/spyfall.html) |
