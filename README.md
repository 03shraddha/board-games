# Board Games

One-laptop, no-phones social deduction games. Open the HTML file in any browser to play.

- **[Secret Hitler](secret-hitler.html)** — 5–10 players — hidden fascists try to pass policies and elect Hitler.
- **[The Resistance: Avalon](avalon.html)** — 5–10 players — good knights run secret quests while hidden evil sabotages them.
- **[One Night Ultimate Werewolf](one-night-werewolf.html)** — 3–10 players — one night of role-swapping, then one vote to catch a werewolf.
- **[Spyfall](spyfall.html)** — 3–8 players — everyone shares a secret location except one spy bluffing to blend in.
